# JEPA Abstraction-Emergence Research Execution Package

**Protocol proposal v1.0 — Markdown edition. No experimental results.**

## Documents

1. [Research Experiment Plan](01_Research_Experiment_Plan.md) — hypotheses, simulator, JEPA variants, behavioral metrics, controls, Stage A–E matrix, statistics and risks.
2. [Coding Agent Instructions](02_Coding_Agent_Instructions.md) — roles, inputs/outputs, configuration, seeds, tests, failure handling and handoffs.
3. [Stepwise Execution Plan](03_Stepwise_Execution_Plan.md) — phases, checkpoints, evidence requirements and go/no-go decisions.
4. [Results & Data Reporting Specification](04_Results_and_Data_Reporting_Specification.md) — metrics, metadata, tables, plots, confidence intervals, dashboard design and result-reporting templates.

## Scope and status

These documents define a small synthetic JEPA-style experiment on reusable physical representations. They are a proposed protocol, not a reproduction of V-JEPA 2 or V-JEPA 2.1, and contain no empirical findings. Numerical defaults and stage definitions must be frozen after pilot validation and before confirmatory test access.

The package was prepared from the supplied preview of the conversation titled *Multi Agent Consensus Experiment* and the requested deliverable specification. The full conversation was unavailable during preparation; newly introduced choices are labeled proposed.

## Companion artifacts

The original downloadable package also contains DOCX documents, an XLSX dashboard, CSV templates, configuration contracts and reference utilities. This repository folder contains the requested Markdown edition only. References in the memos to those companion artifacts describe the full package; the companion files are not included in this folder. Dashboard structure and calculation requirements are documented in the reporting specification.

## Starting point

Review Phase 0 in the execution plan, freeze the metric and oracle information contracts, then validate the simulator and pilot resource budget before dispatching the screening sweeps.
